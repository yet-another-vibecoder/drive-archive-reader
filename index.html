TypingMind Drive Read Only

A personal, unofficial connector for searching and reading Google Drive files and Gmail messages in TypingMind. It runs on the account owner's computer through a local MCP connector. It is not a Google or TypingMind product.

What it does

The connector provides search and read tools for Drive and Gmail. It can extract text from Drive PDFs and EML files locally. Gmail attachment names and metadata are available; reading Gmail attachment contents is not currently supported.

Read-only permissions

Drive requests drive.readonly; Gmail separately requests gmail.readonly. The tools do not send mail, create or delete cloud files, edit messages, or change labels. Reading Gmail does not mark a message as read.

Where information goes

Requested content is returned to TypingMind and can be sent to the AI provider selected by the user. It can remain in the user's chat history, exports or configured backups. The privacy policy explains these data flows and local storage.

Personal use

This installation is operated by its owner for their own accounts. This website is informational; it does not provide a hosted connector, collect credentials, or offer a sign-in service.
